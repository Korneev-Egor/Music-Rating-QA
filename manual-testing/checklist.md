# CL-001 — Чек-лист авторизации

**Проект:** Music Rating. **Область:** форма входа и результат авторизации.

Статусы восстановлены по связанным тест-кейсам, а не по отдельному новому прогону чек-листа. PASS относится к проверенному поведению интерфейса. Not Run означает отсутствие подтверждённого результата в сохранённых материалах.

| ID | Проверка | Статус | Связанный тест-кейс |
| --- | --- | --- | --- |
| CL-001.01 | Вход с корректным логином и паролем | PASS | TC-008 |
| CL-001.02 | Вход с пустым логином | Not Run | — |
| CL-001.03 | Вход с пустым паролем | Not Run | — |
| CL-001.04 | Вход с неверным паролем | PASS (UI) | TC-009 |
| CL-001.05 | Вход с несуществующим логином | Not Run | — |
| CL-001.06 | Перенаправление на главную после успешного входа | PASS | TC-008 |
| CL-001.07 | Сообщение об ошибке при неверных учётных данных (проверен неверный пароль) | PASS (UI) | TC-009 |
| CL-001.08 | Отправка формы кнопкой «Войти» | PASS | TC-008, TC-009 |

**Итог:** 5 пунктов подтверждены связанными тест-кейсами, 3 требуют прогона или восстановления результата.
