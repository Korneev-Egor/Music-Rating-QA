# Test Cases — Music Rating

Ручное функциональное тестирование веб-приложения Music Rating.

**Стенд:** `http://localhost/MUSIC_site_portfolio/` (XAMPP, Windows). Точные версии браузера и сборки для исторических прогонов не зафиксированы.

Результаты восстановлены по сохранённым записям тестирования. `PASS (UI)` — проверенная часть сценария прошла; дополнительные проверки указаны отдельно. Учётные данные заменены обозначениями, чтобы не публиковать пароли и email. Перед повторным прогоном необходимо подготовить соответствующие тестовые данные.

## TC-001 — Поиск существующей композиции

**Тип:** функциональное, позитивное.

**Предусловия:** открыта главная страница; в каталоге есть композиция `test drive` исполнителя Echo Phase.

**Тестовые данные:** название — `test drive`; жанр — все жанры; исполнитель — все исполнители.

**Шаги:**

1. Найти блок «Быстрый поиск композиции».
2. Ввести `test drive` в поисковое поле.
3. Оставить значения «Все жанры» и «Все исполнители».
4. Нажать «Найти».

**Ожидаемый результат:** открывается страница результатов; отображается композиция `test drive` исполнителя Echo Phase.

**Фактический результат:** открылась страница `songs.php`; найдена композиция `test drive` исполнителя Echo Phase, жанр Witch House. Ошибок не выявлено.

**Статус:** PASS (по предыдущей записи о прогоне).

## TC-005 — Успешная регистрация

**Тип:** функциональное, позитивное.

**Предусловия:** открыта страница регистрации; пользователь не авторизован; выбранные логин и email не заняты.

**Тестовые данные:** уникальный логин, новый корректный email, корректный тестовый пароль.

**Шаги:**

1. Ввести уникальный логин.
2. Ввести новый корректный email.
3. Ввести корректный пароль.
4. Нажать «Зарегистрироваться».

**Ожидаемый результат:** регистрация завершается успешно; пользователь перенаправляется на страницу авторизации согласно ранее согласованному сценарию.

**Фактический результат:** появилось уведомление об успешной регистрации, но пользователь остался на `register.php`.

**Статус:** FAIL — [BUG-001](bug-reports.md#bug-001--отсутствует-перенаправление-после-регистрации).

**Ограничение:** запись нового аккаунта в БД отдельно не подтверждена в сохранённом результате.
