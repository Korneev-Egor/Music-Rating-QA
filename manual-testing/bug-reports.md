# Bug Reports — Music Rating

## BUG-001 — Отсутствует перенаправление после регистрации

| Поле | Значение |
| --- | --- |
| Статус | New (на момент исходной фиксации) |
| Severity | Minor (предварительно) |
| Компонент | Регистрация |
| Связанный тест-кейс | [TC-005](test-cases.md#tc-005--успешная-регистрация) |
| Окружение | Локальный стенд Music Rating, XAMPP, Windows; версия браузера и сборки не зафиксирована |
| Воспроизводимость | Зафиксирован один описанный прогон; повторный прогон не подтверждён |

**Предусловия:** открыта страница регистрации; пользователь не авторизован; логин и email свободны.

**Шаги воспроизведения:**

1. Ввести уникальный логин.
2. Ввести новый корректный email.
3. Ввести корректный тестовый пароль.
4. Нажать «Зарегистрироваться».

**Ожидаемый результат:** после успешной регистрации пользователь перенаправляется на страницу авторизации согласно ранее согласованному сценарию.

**Фактический результат:** отображается уведомление об успешной регистрации, но пользователь остаётся на `register.php`.

**Обоснование Severity:** нарушен ожидаемый переход между страницами; интерфейс сообщает об успешной регистрации. Создание записи в БД отдельно не подтверждено, поэтому оценка предварительная.

**Вложения:** исходный скриншот интерфейса не приложен; при повторном прогоне необходимо сохранить обезличенное доказательство.

**Примечание:** описание восстановлено по сохранённой записи тестирования. Учебный пример входа с неверным паролем не включён в список дефектов: фактический TC-009 показал корректное отклонение входа через UI.
